# Raw Data

Сюда складываются сырьевые артефакты, которые можно скачать повторно и при необходимости перепарсить.

## Что здесь может лежать

- сырой Excel World Bank Pink Sheet;
- при желании сырьевые выгрузки других открытых источников;
- ваши локальные входные файлы для валидации.
- локальные DOCX-отчеты СПАРК, если вы хотите держать сырье внутри проекта перед запуском `main_spark.py`.

## СПАРК DOCX

Для парсинга отчетов СПАРК используйте `main_spark.py` и модуль `src/spark_docx_parser.py`.

Подробная инструкция: `docs/SPARK_PIPELINE.md`.

Ожидаемый формат имени файла:

```text
СПАРК-Отчет_<название компании>_<ИНН>_<дата>_<номер>.docx
```

## Что сюда не нужно класть

- токены и секреты;
- финальные Excel-результаты;
- временные ноутбучные файлы.
